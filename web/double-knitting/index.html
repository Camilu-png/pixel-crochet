Double knitting: sigue tu patrón fila a fila

¿Buscas una forma sencilla de seguir un patrón de double knitting? Pixel Crochet es una app gratuita y de código abierto para importar patrones visuales o de texto y consultar qué color y cuántos puntos corresponden a cada fila. La nueva opción double knitting muestra también la inversión de colores de la otra cara.

Para usar double knitting: el patrón debe tener exactamente dos colores. Activa la opción al crear o editar el proyecto para ver la distribución de color intercambiada en la cara inversa.

Cómo empezar

  1. Abre Pixel Crochet y crea un proyecto a partir de una imagen o de un patrón de texto.
  2. Usa un diseño con dos colores y activa la opción Double knitting.
  3. Sigue la fila activa: la app muestra los bloques de color y el conteo para ayudarte a mantener tu lugar.
  4. Consulta la cara inversa con los colores intercambiados y retoma el proyecto más tarde con el progreso guardado.

Una guía para acompañar tu tejido

Pixel Crochet organiza el patrón y el conteo para que puedas concentrarte en tejer. La opción double knitting está disponible para proyectos de exactamente dos colores; si tu patrón tiene más colores, puedes seguirlo con las funciones habituales de la app.

Preguntas frecuentes

¿La app crea patrones de double knitting? Puedes convertir una imagen en una cuadrícula o pegar un patrón de texto para seguirlo. La app te ayuda a leer y contar el patrón; tú eliges el diseño que vas a tejer.

¿Cuántos colores admite la opción? La opción double knitting requiere exactamente dos colores.

¿Cuesta algo? No. Pixel Crochet es gratuita y de código abierto, y funciona en web, Android e iOS.
