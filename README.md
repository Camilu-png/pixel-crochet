# Pixel Crochet
Descripción

Pixel Crochet es una aplicación móvil desarrollada en Flutter diseñada para facilitar el seguimiento de patrones de tapestry crochet.

En lugar de obligar al usuario a contar manualmente cada punto mientras interpreta un patrón, la aplicación convierte un patrón en formato de texto en una guía interactiva que permite avanzar punto por punto, color por color y fila por fila.

El usuario simplemente pega el patrón generado por cualquier herramienta (como Stitch Fiddle u otros generadores de patrones en texto) y la aplicación lo procesa automáticamente, mostrando únicamente la información necesaria para continuar tejiendo.

La aplicación mantiene el progreso automáticamente, permite retroceder si se comete un error y elimina gran parte del conteo manual que normalmente provoca equivocaciones en proyectos grandes.

Objetivos
- Reducir errores de conteo.
- Hacer más cómodo el seguimiento de patrones grandes.
- Eliminar la necesidad de imprimir patrones.
- Poder continuar un proyecto exactamente donde se dejó.
- Ofrecer una interfaz extremadamente simple para usar mientras se está tejiendo.
